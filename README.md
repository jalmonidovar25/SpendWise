# SpendWise

SpendWise is a personal budget and expense tracking web application designed to help users manage their money in an organized and simple way.

## Project Goal

The goal of SpendWise is to make it easier for users to understand where their money is going and help them make better financial decisions.

## General Functionality

- User registration and login
- Add, edit, and delete income and expense records
- Organize transactions into categories
- Set a monthly budget
- Dashboard showing income, expenses, remaining budget, and current balance
- View spending summaries and charts
- Filter transactions by date and category
- Create savings goals
- Store user data in a database
- Explore AI-based features as the project develops
